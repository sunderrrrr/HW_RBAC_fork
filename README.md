### Техническое задание:

#### Описание задачи:
Нужно реализовать систему управления пользователями для бэкенд-сервиса. Система должна уметь создавать пользователей, проверять их права доступа к функциям и эффективно управлять памятью.

#### 1. Класс `User` и управление памятью
*   Создай класс `User`.
*   Используй **`__slots__`**, чтобы ограничить атрибуты: `user_id`, `username`, `role`.
*   Реализуй магический метод **`__str__`** и **`__repr__`**, чтобы вывод был читаемым

#### 2. Иерархия Ролей (ООП и сравнение)
*   Создай систему ролей: `GUEST`, `USER`, `ADMIN`.
*   Роли должны быть сравниваемыми. **ADMIN > USER > GUEST**.

#### 3. Декоратор доступа `@access_level`
*   Напиши декоратор, который принимает уровень роли (например, `@access_level("ADMIN")`).
*   Если у пользователя, который вызывает функцию, уровень прав ниже необходимого, декоратор должен выбрасывать исключение `PermissionError`.
*   **Важно:** Декоратор должен сохранять метаданные оборачиваемой функции (имя, докстринг) — используй `functools.wraps`.

#### 4. Контекстный менеджер `SudoMode`
*   Реализуй класс-контекстный менеджер, который временно повышает роль пользователя до `ADMIN` внутри блока `with`, а после выхода — возвращает старую роль.
